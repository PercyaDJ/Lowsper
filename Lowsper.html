Consignes pour l'IA

Texte placé devant la note par « Copier pour une IA », pour demander un compte rendu à l'assistant de votre choix. Variables possibles, comme dans les modèles de note ; {{note}} place la note ailleurs qu'à la fin.

IA intégrée du navigateur (expérimental)

Chrome et Edge récents peuvent embarquer un petit modèle de langage qui rédige des résumés sur le PC, sans service en ligne, si le matériel le permet.         Déjà installé ailleurs, ou PC sans Internet ?
        
      Vous aviez déjà installé le modèle dans une version précédente de Lowsper ? Inutile de le retélécharger : copiez le dossier app\models de l'ancien dossier Lowsper dans celui-ci (remplacez le dossier existant), puis rechargez la page (F5).
      
        
      Le téléchargement se fait depuis Hugging Face (huggingface.co), à une version figée, et chaque fichier est vérifié par empreinte numérique.
